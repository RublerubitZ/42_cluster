-  패키지 관리
1. 패키지의 설치, 삭제, 업데이트 작업 등에 있어 어떤 패키지가 어디에 설치되어 있는지 등을 관리 및 패키지 간의 충돌을 회피하는 방법을 제공하는 관리 시스템 -> Debian의 관리 시스템
		**Apt && Aptitude**
- APT
1. Advancded Packaging Tool 의 약어
2. 데비안 계열의 리눅스에서 사용되는 패키지 관리 툴
3. GUI없이 명령어로 사용
4. 설치할 패키지 명을 입력시, '/etc/apt/sources.list' 에 지정된 소스 목록에서 해당 패키지 및 종속성 목록과 함께 찾아서 자동으로 설치.
	- apt와 apt-get 의 차이(?)
		apt와 apt-get(apt-cache) 등 내부 동작의 차이는 거의 없음.
		apt-get에서 옵션들이 많아져서, apt에서는 자주 사용하는 옵션들을 추출하여 사용자들이 사용하고 보기 편하게 만듦
		`apt -> 더 예쁘고 추가적인 정보를 출력`
		`apt-get -> 더 많은 옵션 보유( = 더 많은 기능 사용 가능)
			  `-> 오래전부터 존재하여, 더 안정적`

- Aptitude
1. apt의 상위 계층 및 apt 기능 포함 및 더 많은 기능 보유
2. 사용자 인터페이스(GUI/TUI) 보유.
3. Aptitude가 Apt보다 조금더 사용자 친화적.


- APPArmor 시스템
1. 리눅스 애플리케이션 보안 시스템
2. 내외부적 위협으로부터 운영체제와 애플리케이션을 능동적 보호
3. 정책 파일을 바탕으로 어떤 어플리케이션이 어떤 파일에 접근 가능한지 등 애플리케이션이 실행 전 행동을 검사하고 실행여부를 결정( 규칙 집합에 따라 제한 )
4. MAC를 제공해서 Unix DAC를 보완함.(강제적 접근 통제-MAC / 임의적 접근 통제-DAC)
		- **접근 통제 :** 디렉터리나 파일 , 네트워크 소켓같은 **시스템 자원을 적절한 권한을 가진 사용자나 그룹이 접근하고 사용할 수 있게 통제** 하는것을 의미
		- [MAC] : 강제적 접근 통제
			1. 미리 정해진 정책과 보안 등급에 의거, 접근 통제
			2. 자원에 대한 접근은 주체의 보안등급과 객체의 보안레벨에 기반함.
			3. 관리자만이 객체의 보안레벨, 보안등급 수정가능
			4. 높은 보안을 요구하는 정보는, 낮은 보안 수준의 주체 접근X
			5. 객체의 소유자라고 해도, 정책에 어긋날시 객체 접근X
		- [DAC] : 임의적 접근 통제
			1. 시스템 객체에 대한 접근을 사용자나 그룹의 신분을 기준으로 제한
			2. 사용자나 그럼이 객체의 소유자라면 다른 주체에 대해 해당 객체에 대한 접근 권한 설정 가능
			3. 자신의 판단에 의해 권한을 줄수 있어서 **임의적** 이라고 함.

	- 컴퓨터와 컴퓨터가 인터넷과 같은 Public Network 를 통해 서로 통신할 때 보안적으로 안전하기 위해 사용하는 [프로토콜]
	- SSH는 다른 컴퓨터와 통신하기 위해 접속할 때 일반적인 비밀번호 입력 방식 X -> 한 쌍의 key를 통해 접속하려는 컴퓨터와 인증 과정을 거침
		- **Public KEY** - 공개되어도 안전한 키 / 전송시 `암호화` , `복호화 할수 없음`
		- **Private KEY** - 외부 노출 되어서는 안되는 키 / `컴퓨터 내부(로컬) 저장` , `메세지 복호화 가능`

4. apt vs aptitude
	- apt는 로우레벨 패키지 매니저
	- apt는 하이레벨 패키지 매니저이다.

apt는 apt 소스 리스트에서 패키지를 찾아 설치하는 방식으로 조금더 편하게 만들어진 것이지만 로우레벨이므로, CLI단계에서만 지원한다.

aptitude는 apt-get, apt-cache를 포함하여 복잡한 기능을 통합하여 패키지를 보다 사용자 친화적으로 만들었으며 (ex) GUI, TUI지원)
- apt-get은키지 데이터베이스를 업데이트하는것 
- apt-cache는 패키지를 검색 및 정보 확인 하는것.'
- **2가지는 패키지 관리를 하는데 2가지 명령어로 확인해야되서 불편**

이러한 잡다하고 많은 기능들 중에 사용자들이 주로 많이 사용하고 필요한 기능만 넣어서 만든것이 APT

사용자 친화적 단계로 보면 / 

aptitude - apt - apt-get / apt-cache - dpkg

5. AppArmor :: 앱 아머
- 리눅스 보안 모듈 시스템으로써 내 외부적 위험으로써 능동적으로 보호한다.
- 대체로 크게 2가지로 나뉨
- [MAC] : 강제적 접근 통제
	1. 중앙에서 관리자가 설정한 규정에 따라, 주체가 보안등급을 충족하고, 객체가 보안등급이 충족할때 야 너 통과해도되라고 접근이 가능함
	2. 관리자만이 보안레벨, 보안등급 수정가능
- [DAC] : 임의적 접근 통제
	1. 관리자 아닌 사용자가 객체의 소유자일시, 임의로 너도 여기 소유할수 있어 라고 지정하면 그 사람도 똑같이 접근이 가능하기 때문에 임의적 접근 통제이다.

		ex) A = MAC로 i 만 관리자로 접근이 가능하다.[ 중앙 통제 ]
		관리자 -> A / B -> 
		ex) B = j가 객체의 소유자라면 k , l , z 등 아무나 설정가능.
